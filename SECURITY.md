# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue or pull request for a security problem.

Include what you found, the affected version and platform, and steps to reproduce it. You can expect a first reply within 7 days. Confirmed issues are fixed in a new release, and you will be credited in the release notes unless you prefer not to be.

## Scope

Of particular interest: anything that leaks screenshot data, and anything that weakens the signed in-app update flow (for example accepting an unsigned or wrongly signed update).
